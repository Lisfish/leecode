# 242. 有效的字母异位词：初始代码复盘

## 一、初始代码

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1
        for ch in t:
            count[ord(ch) - ord('a')] -= 1
            if count[ord(ch) - ord('a')] < 0:
                return False
        return True
```

> 这段代码可以直接运行，两个示例与全部边界用例均通过。核心思路是「长度剪枝 + 26 位计数数组」，比排序、哈希表写法都更贴合本题「仅小写字母」的约束。

## 二、正确性分析

### 1. 先比较长度

字母异位词必须由完全相同的字符重新排列而成，长度必然相等。长度不同直接返回 `False`，是最便宜的剪枝。

### 2. 用计数数组表示频次差

`count[i]` 表示「第 i 个字母在 `s` 中的出现次数减去在 `t` 中的出现次数」：

- 遍历 `s` 时对应位置 `+1`；
- 遍历 `t` 时对应位置 `-1`。

全部遍历结束后，每个位置都为 `0`，当且仅当两个字符串的字母频次完全一致。

### 3. 提前返回 `False` 为什么正确

遍历 `t` 时若发现 `count[x] < 0`，说明 `t` 中字母 `x` 的次数已经超过 `s` 中的次数。后续字符只会让这个计数继续减小，不可能再回到 0，因此可以立即判定不是异位词。

### 4. 最后直接 `return True` 为什么正确

因为前面已经保证 `len(s) == len(t)`，所以所有计数的总和恒为 0。如果没有任何一项变成负数，也就不可能存在正数（总和为 0 且每项均 ≥ 0，则每项必为 0），因此无需再显式检查一遍全零。

这也说明**长度检查不能省略**。反例：`s = "abc"`、`t = "ab"`，若跳过长度比较，计数数组最后为 `[0, 0, 1]`，没有负数，函数会错误返回 `True`。

### 5. `ord(ch) - ord('a')` 的作用

小写字母的 ASCII 码是连续的（`'a'` = 97，`'z'` = 122），减去 `'a'` 的码点后恰好映射到 `0 ~ 25`，用作数组下标。题目保证只含小写字母，因此下标不会越界。

## 三、测试验证

```text
'anagram' / 'nagaram' -> True   示例 1
'rat'     / 'car'     -> False  示例 2
'a'       / 'a'       -> True
'a'       / 'b'       -> False  同长度但频次不同
'ab'      / 'a'       -> False  长度剪枝分支
'aacc'    / 'ccac'    -> False  提前返回分支
'aabb'    / 'abab'    -> True
'abc'     / 'abd'     -> False
'aab'     / 'abb'     -> False
''        / ''        -> True   题目约束外，代码同样成立
```

另以 20000 组随机小写字符串与 `Counter(s) == Counter(t)` 对拍，结果完全一致。

## 四、可改进之处

### 1. 把 `ord('a')` 提取为常量

`ord('a')` 在内层循环中每次都会调用，虽然开销很小，但可以移到循环外：

```python
base = ord('a')
for ch in s:
    count[ord(ch) - base] += 1
for ch in t:
    count[ord(ch) - base] -= 1
```

注意不要为了「快」直接写魔法数字 `97`，可读性会变差。

### 2. 合并成一次循环

```python
for a, b in zip(s, t):
    count[ord(a) - base] += 1
    count[ord(b) - base] -= 1
```

同样 `O(n)`，遍历次数减半。不过两个方向的加减揉在一起，初学阶段分开写更容易检查。

### 3. `Counter` 一行写法

```python
from collections import Counter

return Counter(s) == Counter(t)
```

标准库直接比较两个字符频次表，时间 `O(n)`、空间 `O(k)`（`k` 为不同字符数）。适合快速验证思路，但建议能手写计数数组。

### 4. 排序写法

```python
return sorted(s) == sorted(t)
```

代码最短，但时间 `O(n log n)`、空间 `O(n)`，本题只含小写字母时不如计数法。

### 5. 字母表不固定时改用字典

26 位数组依赖「字符串仅包含小写字母」这一条件。若字符集不确定（大写字母、数字、中文等），应改用字典（或 `Counter`）计数，空间为 `O(k)`。

## 五、复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :---: | :--- |
| 时间 | `O(n)` | 两次线性遍历，`n` 为字符串长度 |
| 空间 | `O(1)` | 固定 26 个计数位置，与输入规模无关 |

## 六、本题需要记住的点

1. 异位词的判定条件：**长度相同 + 每种字符的频次相同**。
2. 长度不同立即返回 `False`，是最容易想到也最有效的剪枝。
3. 字符集固定且很小时（如小写字母），用数组代替哈希表，常数更小、空间是真正的 `O(1)`。
4. 「`s` 加、`t` 减」的差值计数法是判断两组元素频次是否一致的标准套路，可推广到 383. 赎金信等题目。
5. 提前返回负数后直接 `return True` 的正确性依赖长度检查：等长保证计数总和为 0。
6. 通用性与性能要按题目约束取舍：26 位数组快但只适用于小写字母；字典 / `Counter` 更通用。
